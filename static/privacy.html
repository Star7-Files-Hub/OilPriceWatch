隐私政策

最后更新：2026-09-28 · 全国油价监控（OilPriceWatch）

本服务（以下简称"我们"）是一款提供全国各省成品油零售价与调价预测的工具。 我们极其重视你的隐私。本政策说明我们收集、使用信息的方式。使用本服务即表示你同意本政策。

一、我们收集什么

  • 位置（仅省级，用于选出对应油价）：为了默认展示你所在省份的油价，页面会尝试两种方式， 任何一种都只得到省级结果：
    • 浏览器定位（优先）：经你明确授权后读取设备定位，再由你手机/电脑里的页面自身把坐标换算成省份。 坐标不会发送到我们的服务器，也不经过任何第三方地图服务，换算完即丢弃。
    • IP 推断（兜底）：当你拒绝授权、设备不支持，或页面未运行在 HTTPS 下时， 我们会用你的网络 IP 通过第三方服务推断省级位置。
    两种方式都不采集、不存储精确 GPS 坐标，也不建立你的位置历史。
  • 访问日志：服务器会记录必要的访问信息（如访问时间、IP 地址），用于安全防护与限流，不会用于用户画像。
  • 不收集：我们不要求注册、不收集姓名、手机号、邮箱、账号密码等任何个人身份信息。

二、信息如何使用

  • 仅用于：为你展示对应省份的油价与调价预测；保障服务稳定运行（限流、防护）。
  • 我们不会将你的位置或访问信息出售、出租或共享给任何第三方用于广告或营销。
  • 你可以随时拒绝或撤销浏览器定位授权，页面会自动退回 IP 推断；也可直接在页面上手动选择省份，功能完全不受影响。

三、数据留存

浏览器定位得到的坐标只在你的设备内存中参与一次换算，不做留存。 IP 地理定位结果仅在服务端做短期缓存（用于减少对外接口调用），访问日志按运维常规周期留存后删除。 我们不长期保存可追溯到你个人的位置记录。

四、第三方数据源

油价与原油行情来自公开免费数据源：

  • 汽油价格网（qiyoujiage.com）—— 各省零售价与网站预测值
  • 新浪财经（finance.sina.com.cn）—— 国际原油实时/历史行情
  • IP 地理定位（ip-api.com）—— 仅在你未授权浏览器定位时用于推断省级位置
  • 省级行政边界数据（随页面一起下发，在本机参与换算，不产生任何网络请求）

这些数据的准确性与时效性以各数据源为准，调价预测为按公开调价机制的确定性推算，仅供参考，不构成任何决策依据。

五、你的权利

你可随时在页面手动切换省份，无需依赖自动定位。如对本政策或数据处理有疑问，可通过项目主页联系我们。
