隐私政策

最后更新：2026-09-21 · 全国油价监控（OilPriceWatch）

本服务（以下简称"我们"）是一款提供全国各省成品油零售价与调价预测的工具。 我们极其重视你的隐私。本政策说明我们收集、使用信息的方式。使用本服务即表示你同意本政策。

一、我们收集什么

  • 粗略位置（省级）：为向你展示所在省份的油价，我们会根据你的网络 IP 地址推断你所在的省级行政区。这是粗略的地理位置，不采集精确 GPS 坐标。
  • 访问日志：服务器会记录必要的访问信息（如访问时间、IP 地址），用于安全防护与限流，不会用于用户画像。
  • 不收集：我们不要求注册、不收集姓名、手机号、邮箱、账号密码等任何个人身份信息。

二、信息如何使用

  • 仅用于：为你展示对应省份的油价与调价预测；保障服务稳定运行（限流、防护）。
  • 我们不会将你的位置或访问信息出售、出租或共享给任何第三方用于广告或营销。

三、数据留存

IP 地理定位结果仅在服务端做短期缓存（用于减少对外接口调用），访问日志按运维常规周期留存后删除。我们不长期保存可追溯到你个人的位置记录。

四、第三方数据源

油价与原油行情来自公开免费数据源：

  • 汽油价格网（qiyoujiage.com）—— 各省零售价与网站预测值
  • 新浪财经（finance.sina.com.cn）—— 国际原油实时/历史行情
  • IP 地理定位（ip-api.com）—— 仅用于推断省级位置

这些数据的准确性与时效性以各数据源为准，调价预测为按公开调价机制的确定性推算，仅供参考，不构成任何决策依据。

五、你的权利

你可随时在页面手动切换省份，无需依赖自动定位。如对本政策或数据处理有疑问，可通过项目主页联系我们。
